Use this procedure to access the API Compliance module in the APIwiz platform. The API Compliance module lets you view captured API traffic and validate it against your published OpenAPI Specifications.

# Prerequisites

- Before you use API Compliance, ensure the following requirements are met:
- A published OpenAPI Specification \(OAS\) is available for the API you want to validate.
- The APIwiz Observability Traffic Hooks are configured with the correct OAS. This configuration is required for successful traffic ingestion and enables the system to capture and analyze runtime API traffic.

# Access the API Compliance 

To open the API Compliance module, follow these steps:

1. Sign in to the APIwiz platform with your credentials.
1. On the left side of the screen, point to the vertical navigation bar to view the names of the available modules.
1. Select **API Compliance**.
  ![](https://admin.apiwiz.io/api/guides/images/6a7451b5f5e02aabad959a6c)

The API Compliance module opens.
