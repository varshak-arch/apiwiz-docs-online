This quickstart walks you through for setting up and deploying an API through the Ngnix gateway in APIwiz:

**Configure prerequisites**: Add Certificates, Upstreams, and Products under the **Manage** tab.

**Create plugins** \(optional\): Set up any custom or predefined plugins under the **Plugin** tab before building your service.

**Design the service**: Select **\+** in the **API** tab and configure Spec Upload \(optional\), API Data, and Routes.

**Attach plugins**: Apply plugins to routes or the full API through the **API Plugins** node.

**Deploy**: Select **Deploy** on the Create Service canvas. The service is pushed to the Nginx gateway.

**Publish as a Product**: Group the deployed service into a product under the **Manage** tab.

**Manage**: Use Servers to configure runtime listeners, Certificates to maintain SSL/TLS security, and Global Policies to apply governance rules across a connector.
