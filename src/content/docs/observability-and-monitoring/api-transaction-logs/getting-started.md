Use this procedure to access the API Transaction Logs module in the APIWiz platform. The API Transaction Logs module gives you visibility into API requests, responses, and operational events during runtime.

### Prerequisites

Ensure that the [APIWiz traffic hooks](https://drive.google.com/drive/folders/1bbFvAmidm5jqUdeLHAEmf2qbyZXwZQfZ?usp=sharing) are configured with the correct index details. This configuration is required for successful log ingestion.

### Access API Transaction Logs

To open the API Transaction Logs module, follow these steps:

1. Sign in to the APIWiz platform with your credentials.
1. On the left side of the screen, point to the vertical navigation bar to view the names of the available modules.
1. Select **API Transaction Logs**.
  ![](https://admin.apiwiz.io/api/guides/images/6a7c34b8eb3c9603a6c47849)

The API Transaction Logs module opens.
