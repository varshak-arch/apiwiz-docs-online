The following steps outline the end-to-end process for creating, configuring, and running a monitor workflow in API Monitoring.

1. [**Create a workflow**](/observability-and-monitoring/api-monitoring/build-and-monitor/monitor-workflow/)**:** Select the **\+** icon in the top-left panel to create a new workflow.
1. [**Configure the request node and scheduler**](/observability-and-monitoring/api-monitoring/build-and-monitor/configure-request-node/): Select the **Start** node, provide the name, description, and other required details, and add a scheduler with the required interval. Save the configuration. The workflow now executes automatically at the scheduled interval.
1. [**Configure nodes**](/observability-and-monitoring/api-monitoring/build-and-monitor/configure-nodes/)**:** Select the **\+** icon to open the list of available workflow nodes. Add, configure, and save each node the workflow requires.
1. [**Review events**](/observability-and-monitoring/api-monitoring/build-and-monitor/events-and-logs/)**:** Select the **Events** tab to view all scheduled workflow execution events, review logs, identify issues, and debug the workflow as needed.
1. [**Review insights**](/observability-and-monitoring/api-monitoring/build-and-monitor/insights/)**:** Select the **Insights** tab to review uptime, performance, and trend data across all monitor workflows.
