---
title: "Configuration"
---

The right-side panel provides access to configuration and management options for the API Monitoring environment.

![](https://admin.apiwiz.io/api/guides/images/6ab38b1d9f4820a19e5de8c5)

Configuration in API Monitoring works the same way as in API Builder, with the following differences:

- [**Environments**](https://docs.apiwiz.io/guides?guideId=6a606b3c69d1ae970571f1d9&pageId=6a82f8f6f0c8e28fcc1bb364&groupId=Manage), [**Certificates**](https://docs.apiwiz.io/guides?guideId=6a606b3c69d1ae970571f1d9&pageId=6a82f9aff0c8e28fcc1bb3c4&groupId=Manage), [**Data archive**](https://docs.apiwiz.io/guides?guideId=6a606b3c69d1ae970571f1d9&pageId=6a82faa7f0c8e28fcc1bb487&groupId=Manage), and [**Shared flows**](https://docs.apiwiz.io/guides?guideId=6a606b3c69d1ae970571f1d9&pageId=6a82fad5f0c8e28fcc1bb4a1&groupId=Manage) are supported in API Monitoring.
- **SCM configuration**, **Virtual host configuration**, **Workflow deployment**, and the **User Task Dashboard** are not supported in API Monitoring.
