Use this procedure to access the API Tracing module in the APIwiz platform. The API Tracing module gives you end-to-end visibility into how each request flows through your system, across every service, database, and message queue it touches.

## Prerequisites

Ensure that Traffic Hooks are configured for your environment. Traffic Hooks capture API traffic and forward it to APIwiz, and traces appear in API Tracing only after they're set up. See [Traffic Hooks](/agent-based-instrumentation/apiwiz-traffic-hooks/overview/) for setup instructions.

## Accessing API Tracing

To open the API Tracing module:

1. Sign in to the APIwiz platform with your credentials.
1. On the left side of the screen, point to the vertical navigation bar to view the names of the available modules.
1. Select **API Tracing**. 
  ![](https://admin.apiwiz.io/api/guides/images/6a730dd267839bf43da9f770)

The module opens the Trace List, which shows all captured traces within the selected time range.
