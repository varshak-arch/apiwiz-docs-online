This quickstart walks you through the end-to-end process for viewing traces in API Tracing.

1. [**Configure Traffic Hooks**](https://admin.apiwiz.io/admin/guides?guideId=6a67165669d1ae9705725814&pageId=6a6b109569d1ae9705729fa3)**: **Ensure Traffic Hooks are configured to capture API traffic and forward it to APIwiz.
1. [**Configure Trace Headers**](/observability-and-monitoring/api-tracing/settings/)**: **Select **Configure Trace Headers** from the right panel and define the required header aliases used to identify and correlate traces.
1. [**View Incoming Traces**](/observability-and-monitoring/api-tracing/trace-list/)**: **Once traffic is captured, traces appear in the **Trace List**. Select a trace to view its complete request journey, including API calls, database interactions, and message queue operations.
1. [**Analyze the Trace**](/observability-and-monitoring/api-tracing/trace-view/)**: **Use the **Trace** tab to inspect the request flow and individual spans, or use the **Performance** tab to identify services or database operations contributing to latency.
