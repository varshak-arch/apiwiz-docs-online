Guides and API references for the Dev Portal are created and published in Docuwiz. To connect your Dev Portal to Docuwiz and start creating guides, see the [Docuwiz documentation](https://documentation.docuwiz.io/).

Administrators can hide the Guides and References entry points for specific roles. For more information, see [Access Control List.](/monetize/api-marketplace/setup-and-configuration/users/)
