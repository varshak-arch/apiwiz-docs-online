title: "Manage tab"
---

Monetization entities, also called monetization configs, are the backend dependencies an API provider configures before creating or publishing a monetization package.

Rather than configuring pricing rules for each package individually, you pre-configure these reusable building blocks under the **Manage** tab. These configs define the financial, technical, and organizational rules of your marketplace.

### Monetization entities

The platform includes five core monetization entities.

- **Rate cards**: Define the pricing structure applied when a consumer calls your API.
- **Currency sets**: Define the group of currencies you transact in.
- **Companies**: Support corporate billing instead of individual consumer billing.
- **Metering rules**: Define the technical criteria on an API request or response that trigger a charge.
- **Package categories**: Group and display packages on your developer portal marketplace.

### Accessing Manage Configs

To access Manage Configs, select **API Monetization \> Manage**.

![](https://admin.apiwiz.io/api/guides/images/6a60f80869d1ae970572088f)

The **Manage** tab opens, displaying the monetization entities available for configuration.
