---
title: "Reviewing key performance metrics"
---

The dashboard displays key performance indicators \(KPIs\) that help you monitor the health and performance of your API monetization program. Use these metrics to track customer adoption, revenue growth, consumer retention, and overall monetization performance.

The dashboard includes the following metrics.

### Total Companies

The **Total Companies** card displays the total number of companies configured for API monetization during the selected reporting period.

Use this metric to monitor organizational adoption of your monetized APIs. The percentage indicator shows the change in the number of companies compared to the previous 30-day period.

### Monthly Recurring Revenue \(MRR\)

The **Monthly Recurring Revenue \(MRR\)** card displays the recurring revenue generated from active API subscriptions.

Use this metric to monitor predictable monthly revenue and evaluate the overall financial performance of your API monetization program.

### Consumer Churn Rate

The **Consumer Churn Rate** card displays the percentage of consumers who stopped using your monetized APIs during the selected reporting period.

Use this metric to monitor consumer retention and identify potential issues that may affect customer adoption, such as pricing, API performance, or usability.

### Net Promoter Score \(NPS\)

The **Net Promoter Score \(NPS\)** card provides an overview of consumer satisfaction with your published API packages.

Use this metric to evaluate how consumers perceive your APIs based on usability, performance, and overall experience. The card groups API packages into rating ranges, helping you quickly identify highly rated packages and those that may require improvement.

### Average API Monetization

The **Average API Monetization** card displays the average revenue generated per consumer during the selected reporting period.

Use this metric to evaluate how effectively your APIs generate revenue across your consumer base. The percentage indicator shows the change in average monetization compared to the previous 30-day period.

### Average Consumer Spending

The **Average Consumer Spending** card displays the average amount spent by active consumers during the selected reporting period.

Use this metric to understand average consumer spending patterns and monitor changes in revenue contribution over time. The percentage indicator compares the current period with the previous 30-day period.
