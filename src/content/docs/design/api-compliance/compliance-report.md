---
title: "Compliance report"
---

Use the **Generate Report** option to export API compliance data in CSV or HTML format for analysis, auditing, and offline review.

To generate a compliance report:

1. In the **API Compliance Inventory**, select **Generate Report**.
1. Select the required report format: **CSV** or **HTML**.

The available fields depend on the selected report format.

# Generate a CSV report

CSV reports run as background jobs and become available for download after processing completes.

![](https://admin.apiwiz.io/api/guides/images/6a75ede145267d9515c9f81c)

To generate a CSV report:

1. Enter the following details:

1. Select **Generate**.

The platform queues the report as a background job. After the job completes, download the report from **Report History**.

## Download a generated report

To download a generated report:

1. Select **Generate Report** dropdown \> **Report History**.
  ![](https://admin.apiwiz.io/api/guides/images/6a79269c45267d9515ca0262)
1. Locate the required report.
1. Select the **Download** icon next to the report.
  ![](https://admin.apiwiz.io/api/guides/images/6a7926d145267d9515ca0284)

The report is downloaded to your local system.

# Download an HTML report

HTML reports generate and download immediately, for a single environment.

![](https://admin.apiwiz.io/api/guides/images/6a75ed6a45267d9515c9f7ec)

1. Enter the following details:

1. Select **Download**.

The platform generates the report and downloads it as an HTML file.

## Report contents

The generated report contains API compliance data based on the selected report type, filters, date range, and environment. The report includes relevant compliance metrics and runtime information available for the selected APIs.

Use the report to analyze API compliance, monitor governance, identify potential issues, and share compliance insights with stakeholders.
