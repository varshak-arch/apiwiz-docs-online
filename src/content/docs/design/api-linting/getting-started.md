Use this procedure to access the API Linting module in the APIwiz platform. The API Linting module lets you create and execute validation rules against your API specifications to enforce governance, consistency, and quality standards.

# Prerequisites

Ensure that the following specifications are created in Design Studio:

- **OAS \(OpenAPI Specification\)**
- **AsyncAPI**
- **Data Dictionaries**

This is required for creating and executing API linting rules.

# Accessing API Linting

To open the API Linting module:

1. Sign in to the APIwiz platform with your credentials.
1. On the left side of the screen, point to the vertical navigation bar to view the names of the available modules.
1. Select **API Linting**.
  ![](https://admin.apiwiz.io/api/guides/images/6a828feaf0c8e28fcc1ba178)

The API Linting module opens.
