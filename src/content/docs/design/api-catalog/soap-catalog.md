The **SOAP** tab lists all published SOAP specifications. Each specification represents a SOAP service defined in a Web Services Description Language \(WSDL\) document. Expand a service in the **References** panel to browse its overview and operations.

![](https://admin.apiwiz.io/api/guides/images/6af69d2a8de819ecd3bc0be9)

## The References panel

On the **SOAP** tab, the **References** panel includes the **Search APIs** field, the filter icon, and the service tree. Expand a service to see the following:

To search and filter GraphQL APIs, use the same procedures as for OAS. For more information, see [**Search for an API**](/design/api-catalog/oas-catalog/) and [**Filter the catalog**](/design/api-catalog/oas-catalog/) in Browsing the OAS catalog.

## View a SOAP service overview

To view the overview, in the **References** panel, expand a service and select **Overview**.
