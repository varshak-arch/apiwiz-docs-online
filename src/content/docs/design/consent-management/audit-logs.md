The **Audit Logs** tab is where you view all consent data submitted by users through the client's application. When a user submits their data, the client's application sends it to the APIwiz backend via API, and it is automatically populated here.

### Manage Columns

Use **Manage Columns** to configure the columns displayed in the Audit Logs table. You can add new columns, edit existing columns, or remove columns based on your consent group requirements.

To manage columns, follow these steps:

1. In the **Audit Logs** tab, in the upper-right corner, select **Manage Columns**.
  ![](https://admin.apiwiz.io/api/guides/images/6a50e2b0d21aefbd0a9eddf3)
1. The **Manage Columns** panel opens.
  ![](https://admin.apiwiz.io/api/guides/images/6a50e31bd21aefbd0a9ede19)
1. To create a new column, select **\+**. The **New Column** form opens.
  ![](https://admin.apiwiz.io/api/guides/images/6a50e434d21aefbd0a9ede59)
1. Select the column type:

1. Enter the following details:

1. If you selected **Multi Value**, select **\+ Add Options** and enter one or more values that users can choose from.
1. Select **Save**.

The new or updated column is available in the Audit Logs table. When matching data is received from the client application, the corresponding values are displayed in the configured columns.
