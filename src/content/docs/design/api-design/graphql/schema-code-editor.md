---
title: "Schema Code Editor"
---

The Schema Code Editor, located on the right side of the interface, lets you define and modify the GraphQL schema directly using the GraphQL Schema Definition Language \(SDL\).

### Direct editing

You can enter and modify schema definitions directly in the Schema Editor, including types, queries, mutations, inputs, unions, enums, directives, and scalars.

Changes you make in the editor are automatically reflected in the GraphQL design canvas, ensuring real-time synchronization between the code view and the visual representation.

The schema editor supports defining custom scalars while keeping the schema synchronized with the visual design view. This gives you precise control over the schema structure without losing alignment with the graphical representation.

### Violations

The **Violations** panel appears at the bottom of the editor and displays validation issues in the GraphQL schema.

To review violations, follow these steps:

1. Select **Violations** to view all detected issues.
1. Review each violation. Each one highlights a rule or syntax problem that must be addressed.

The panel lists the total number of violations, for example, three violations.
