This quickstart walks you through the end-to-end process of creating, configuring, saving, and publishing a GraphQL schema.

1. [Create a schema](https://docs.apiwiz.io/guides?guideId=6a22b872070047a3a81f4972&groupId=Working+with+GraphQL&pageId=6a323be92b6d03e0ddd4ed96)**: **In **API Design**, go to the **OAS** page, then select the **Add** icon. Choose **New** to create a schema from scratch, or **Sample** to start with an existing template.
1. [Configure the schema type](#configure-the-schema-type)**: **Select the **\+** button, then select a component type to add, such as **Type**, **Interface**, **Union**, **Input**, **Enum**, **Scalar**, or **Directive**. Alternatively, define the schema directly in the editor.
1. [Save the schema](#save-the-schema)**: **After you configure all required entities, select **Save** in the upper-right corner to store the specification.
1. [Update the schema status](#update-the-schema-status)**: **Update the schema's lifecycle status as required, choosing from **Review**, **Approved**, or **Publish**.
