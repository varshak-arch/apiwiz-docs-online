---
title: "Exploring Key Elements"
---

The **Overview** panel on the left side of the **Design** page displays high-level information about the selected OAS.

It includes the following details:

![](https://admin.apiwiz.io/api/guides/images/6a54acdb3c41693bb70f2b2f)

- **API Name**: The name of the OAS.
- **Revision Number**: The current revision number of the specification.
- **Status**: The current state of the OAS, such as Draft, Approved, or Published.
- **API Information**: The API summary and description.
- **Edit icon**: Select this icon to modify the basic OAS details.
- **Redirect Link**: Appears only when an external documentation URL is provided during OAS creation. Select this icon to open the external documentation.
- **More Options menu \(⋮\)**: Provides access to additional OAS management actions.

At the bottom of the **Overview** panel, the following tabs are available:

- [**Paths**](https://docs.apiwiz.io/guides?guideId=6a22b872070047a3a81f4972&groupId=Working+with+OAS&pageId=6a33760acf1933e4d4c0feda): Displays the API resource paths defined in the OAS.
- [**Local Components**](https://docs.apiwiz.io/guides?guideId=6a22b872070047a3a81f4972&groupId=Working+with+OAS&pageId=6a336bb8cf1933e4d4c0ec5b): Displays components defined locally within the current OAS revision.
