This quickstart describes the end-to-end process for creating an OpenAPI Specification \(OAS\) in Design Studio.

1. [Create a specification](https://docs.apiwiz.io/guides?guideId=6a22b872070047a3a81f4972&groupId=Working+with+OAS&pageId=6a2bb23fe5e2da36963ca7a4): Go to the OAS page in API Design and select **\+** to create a new specification.
1. [Configure servers](https://docs.apiwiz.io/guides?guideId=6a22b872070047a3a81f4972&groupId=Working+with+OAS&pageId=6a336bb8cf1933e4d4c0ec5b#9360a6ec-9089-4371-9324-520ba5141ae9): Add the server information that the specification will use.
1. [Configure data models](https://docs.apiwiz.io/guides?guideId=6a22b872070047a3a81f4972&groupId=Working+with+OAS&pageId=6a336bb8cf1933e4d4c0ec5b#ba8025a1-4cd3-4954-8a4d-5e4674e9c5da): Add the required data models for the specification.
1. [Configure APIs](https://docs.apiwiz.io/guides?guideId=6a22b872070047a3a81f4972&groupId=Working+with+OAS&pageId=6a33760acf1933e4d4c0feda): Define the API endpoints, including paths, operations, request details, response structures, tags, and security information.
1. [Save the specification](https://docs.apiwiz.io/guides?guideId=6a22b872070047a3a81f4972&groupId=Working+with+OAS&pageId=6a2bc11ae5e2da36963caac5): In the upper-right corner, select **Save**.
1. [Change the specification status](https://docs.apiwiz.io/guides?guideId=6a22b872070047a3a81f4972&groupId=Working+with+OAS&pageId=6a2bc15ce5e2da36963caacf): Update the status so the specification can be approved or published. If an approval workflow is configured, the specification must complete that process before it becomes available in the Catalog.
1. [Tag environments](https://docs.apiwiz.io/guides?guideId=6a22b872070047a3a81f4972&groupId=Working+with+OAS&pageId=6a2bd38ee5e2da36963cb2b7): After approval, tag or deploy the specification to the appropriate environment.
1. [Try out the APIs](https://docs.apiwiz.io/guides?guideId=6a22b872070047a3a81f4972&groupId=Working+with+OAS&pageId=6a2bd89be5e2da36963cb5bb#2fb84f7e-d1d3-436d-9571-dd143a344e04): Use the **Preview** tab to test the APIs defined in the specification.
