---
title: "Other ways to generate an OAS"
---

In addition to Design Studio, APIwiz provides two alternative ways to generate an OpenAPI Specification \(OAS\) from existing API data:

- **API Inventory**: Generates an OAS from APIs discovered or observed in your environment.
- **API Compliance**: Generates an OAS based on existing API behaviour captured in the Compliance module.

These methods reduce manual effort by deriving API specifications from observed or existing API data.
