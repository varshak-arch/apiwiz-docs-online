Use the **Postman Collection** method to create an OAS by uploading a JSON file exported from your Postman repository.

### Import an OAS from a Postman collection

To import an OAS from a Postman collection, do the following:

1. Select the **Postman Collection** card. The **Postman Collection** configuration panel opens in the right pane.
1. Download the collection file from Postman as a .zip file. For detailed instructions, see [Exporting data from Postman](https://learning.postman.com/docs/getting-started/importing-and-exporting/exporting-data/).
1. In the right pane, select **Browse** and select the .zip file from your computer. The .zip file must contain both the environment folder and the collection folder.
1. Select **Sync**. If the sync is successful, a confirmation message appears in the bottom-right corner. The system redirects you to the **Design Studio** landing page and the newly created OAS appears in the left pane. If you attach the wrong environment to the file, an error message appears in the bottom-right corner.
1. Select the OAS from the left pane to view its details in the **Spec Overview** panel.
1. Select **Edit** in the **Spec Overview** panel to begin designing the OAS.
