Changes made in any tab are saved and can be viewed in the **Design** tab after selecting **Save**.

![](https://admin.apiwiz.io/api/guides/images/6a5733823c41693bb70f585e)

The top panel in the Data Dictionary Design module includes the following tabs that allow you to switch between different views of your data model:

### Data Models section

All created models appear in the **Data Models** section of the **Overview** panel, below the API name and revision. Each model represents the structure of a request or response payload used by the API.

The left panel displays the Data Dictionary and all available data models, along with a summary of the total number of models and their statuses.

### Model Structure Viewer

The **Design** tab displays the model structure of the selected model, providing a visual representation of fields, their types, and relationships.

The central canvas displays data models and their relationships in a graphical layout. Nested elements are displayed as linked sub-blocks, providing a clear visual hierarchy.

Selecting a model from the list opens its detailed structure in the **Model Structure Viewer**.

### Zoom controls

The following zoom controls are available on the right side of the canvas:

- Select **\+** to zoom in.
- Select **-** to zoom out.
- Select **Fit-to-screen** to automatically adjust the view so the entire model fits within the visible canvas.

### Model Revision dropdown

The **Model Revision** dropdown is located in the top-right corner of the canvas. Use it to switch between different revisions of a data model. This is useful for tracking changes, rolling back to a previous version, or maintaining multiple iterations.

### Status indicator

The status indicator appears next to the revision number and displays the current state of the model revision.
