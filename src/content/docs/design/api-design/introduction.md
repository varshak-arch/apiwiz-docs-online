**APIwiz** Design Studio is a collaborative workspace for designing and documenting APIs that follow the OpenAPI Specification \(OAS\). Use Design Studio to create data models, define API operations, and maintain API governance throughout the design phase of the API development lifecycle.

Design Studio uses a model-driven approach. Teams define data models before designing the API operations that interact with those models. This approach ensures that APIs are built on a consistent data architecture and reduces errors caused by data inconsistencies early in the development cycle.

The OpenAPI Specification \(OAS\) is the foundation for API governance in Design Studio. All live API traffic is validated against the defined specification to ensure that requests and responses conform to the documented contract. This validation improves consistency, security, and compliance across your APIs.

Use Design Studio to perform the following tasks:

- Design and document APIs following the OpenAPI Specification.
- Create and manage data models before defining API operations.
- Define endpoints, operations, parameters, and responses.
- Collaborate with team members in a shared workspace.
- Maintain API governance during the design phase.
