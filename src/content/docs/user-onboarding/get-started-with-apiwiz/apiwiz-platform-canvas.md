The APIwiz platform canvas provides a unified view of the platform and its core capabilities. It covers the complete API lifecycle, including design, development, governance, security, integration, observability, publishing, and monetization.

The platform is organized into four layers:

- API consumers
- Data plane
- Integration and orchestration
- Platform engineering

# Data plane

The data plane processes API traffic between consumers and backend services. It provides runtime capabilities for security, routing, orchestration, transformation, and observability.

## API gateway

The API Gateway is the central control point for managing API requests and responses.

## Core orchestration

Core orchestration enables you to build, automate, and manage API workflows.

## Connectivity

The connectivity layer enables integration with internal systems, cloud services, databases, and third-party platforms.

## Triggers

Triggers determine how workflows are initiated.

# Integration and orchestration layer

The integration and orchestration layer enables communication between APIs, applications, services, and enterprise systems. The platform includes more than 100 prebuilt connectors that simplify integration with commonly used technologies.

# Platform engineering

The platform engineering layer provides governance, automation, compliance, observability, and lifecycle management capabilities for enterprise-scale API operations.
