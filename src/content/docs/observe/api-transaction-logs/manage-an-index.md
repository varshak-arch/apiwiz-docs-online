---
title: "Manage an index"
---

In the top-left corner, select **Manage** to view, update, clone, or delete an index.

![](https://admin.apiwiz.io/api/guides/images/6a7ac33a45267d9515ca3ad0)

## Edit an index

To edit an index, locate it in the list; the configuration details appear in the right panel. Update the fields as needed and select **Save**. Changes take effect for subsequent log ingestion.

## Delete an index

To delete an index, locate the index you want to delete and select the Delete \(trash bin\) icon. The index is permanently removed from the index list.

## Clone an index

To clone an index, locate it and select Clone \(copy\). The Index Configuration form opens with the details prefilled; modify as needed, then select **Save** to create a new index based on the cloned configuration.

## Filter logs by date and time range

Use the time range filter to display log data for a specific time period.

To filter logs by time range:

1. In the upper-right corner of the page, select a time unit: **sec**, **min**, **hour**, **day**, **week**, or **custom**.
  ![](https://admin.apiwiz.io/api/guides/images/6a69fd0969d1ae9705729509)
1. Select the required time interval.
1. Select **Apply Range**.

The logs table refreshes and displays log events for the selected time range.
