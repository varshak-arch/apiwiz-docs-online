Use this procedure to access the Application Logs module in the APIWiz platform. The Application Logs module gives you visibility into runtime log data generated directly from your application code.

### Prerequisites

Configure [APIWiz traffic hooks](https://drive.google.com/drive/folders/1bbFvAmidm5jqUdeLHAEmf2qbyZXwZQfZ?usp=sharing) within your application environment before you start ingesting application logs.

### Access Application Logs

To open the Application Logs module, follow these steps:

1. Sign in to the APIWiz platform with your credentials.
1. On the left side of the screen, point to the vertical navigation bar to view the names of the available modules.
1. Select **Application Logs**.
  ![](https://admin.apiwiz.io/api/guides/images/6a6a365269d1ae97057298e4)

The Application Logs module opens.
