This section introduces the **API Monitoring** interface and explains how to access the module in the APIWiz platform.

# Access API Monitoring

To open the API Monitoring module:

1. In your browser, go to the **APIWiz platform** and sign in with your credentials.
1. In the left vertical navigation bar, select **API Monitoring**.
  ![](https://admin.apiwiz.io/api/guides/images/6ab38c6b9f4820a19e5de9cc)

The API Monitoring module opens, where you can build, schedule, and manage your monitor workflows.
