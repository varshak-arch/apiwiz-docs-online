---
title: "Trace List"
---

The Trace List is the main landing page of the API Tracing module. It displays all captured traces within the selected time range, giving you a starting point for investigating API behavior and failures.

**Date and time filter**

Use the date and time selector in the top-right corner to define the time range for the traces displayed. Select the refresh icon to reload the latest data.

**Trace List columns**

Select any row in the Trace List to open the full trace detail view for that request.

![](https://admin.apiwiz.io/api/guides/images/6a730e0c67839bf43da9f7b7)

### Filters

Select the **Filters** panel on the left side of the Trace List to narrow down traces by specific criteria.

Select **Filter** to apply. Select the filter icon again to clear or update filters.

![](https://admin.apiwiz.io/api/guides/images/6a730e2067839bf43da9f80f)
