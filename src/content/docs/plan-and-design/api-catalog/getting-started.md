Open the **API Catalog** module to browse and test the APIs published in your organization. The catalog groups APIs by specification type, and the **OAS** tab opens by default.

**Prerequisites**

At least one API specification \([OAS](/plan-and-design/api-design/introduction/), [GraphQL](/plan-and-design/api-design/graphql/overview/), or [SOAP](/plan-and-design/api-design/soap/overview/)\) is published to the catalog.

## Access the API Catalog module

To open the API Catalog, follow these steps:

1. Log in to the APIwiz platform.
1. Hover over the left navigation bar to expand it, and then select **API Catalog**.
  ![](https://admin.apiwiz.io/api/guides/images/6af5c137897f63d843981a20)

The API Catalog opens on the **OAS** tab, with published OAS specifications listed in the **References** panel.
