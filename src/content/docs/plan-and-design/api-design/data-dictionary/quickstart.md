This quickstart walks you through the end-to-end process of creating a data dictionary, building data models within it, managing their status, and validating the data dictionary through linting.

1. [Create a data dictionary](https://docs.apiwiz.io/guides?guideId=6a22b872070047a3a81f4972&groupId=Working+with+OAS&pageId=6a27bf11070047a3a81f543d#0b87a40b-10f8-4565-803f-5837e5b181d3)**: **In the **OAS** section, go to **Components**, then select the **\+ \(Add\)** icon to create a new data dictionary.
1. [Create a data model](https://docs.apiwiz.io/guides?guideId=6a22b872070047a3a81f4972&groupId=Working+with+Data+Dictionary&pageId=6a2fe5f92b6d03e0ddd4ccc7#661ad903-a54a-459d-9275-5e87597bf3c0)**: **Select the **More** \(⋮\) menu, then select **Edit**, and create a data model from scratch, by importing a database schema, or by importing a valid JSON file.
1. [Change the status of a data model](https://docs.apiwiz.io/guides?guideId=6a22b872070047a3a81f4972&groupId=Working+with+Data+Dictionary&pageId=6a30cc5a2b6d03e0ddd4d129#e691264b-0715-4132-82ce-3494f6891cc1)**: **Select the **More** \(⋮\) menu for the data model, select **Change Status**, then update the status as required.
1. [Change the status of a data dictionary](https://docs.apiwiz.io/guides?guideId=6a22b872070047a3a81f4972&groupId=Working+with+Data+Dictionary&pageId=6a30e0ef2b6d03e0ddd4d52c#fcc74c00-30c5-4dcf-8821-6f5c2dbfd741)**: **Select the **More** \(⋮\) menu at the top-left of the data dictionary, then update the status as required.
1. [Trigger linting](https://docs.apiwiz.io/guides?guideId=6a22b872070047a3a81f4972&groupId=Working+with+Data+Dictionary&pageId=6a30e21c2b6d03e0ddd4d5fe)**: **In the **Linting** tab of the data dictionary, select the required ruleset, then trigger linting to validate the data dictionary.
