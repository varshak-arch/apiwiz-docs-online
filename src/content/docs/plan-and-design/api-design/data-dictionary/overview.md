A Data Dictionary is a centralized repository that defines and describes the data models and fields used across an API program. It acts as a catalog that ensures a shared understanding of how data is structured, exchanged, and validated within APIs.

In the context of the OpenAPI Specification \(OAS\), Data Dictionaries are foundational for designing consistent, well-documented, and maintainable APIs.
