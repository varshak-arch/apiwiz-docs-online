OpenAPI Specification \(OAS\) is a standardized contract that defines an API's structure, behavior, and interactions. Presented in YAML or JSON format, OAS serves as a single source of truth for both API development and consumption. It provides a consistent blueprint that development teams, partners, and tools can rely on throughout the API lifecycle.

# Need for standardization

Without a universal standard, different teams and organizations document APIs inconsistently, making it difficult for internal and external developers to understand and consume those APIs. For example, one team may document authentication requirements in a README file while another embeds the same information in code comments, making it impossible to validate or automate either approach.

The OAS module in Design Studio addresses this by providing a single, universal standard for defining and documenting REST APIs across the APIwiz platform.
