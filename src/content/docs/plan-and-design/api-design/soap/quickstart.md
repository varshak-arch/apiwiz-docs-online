This quickstart walks you through the end-to-end process of creating, configuring, validating, and publishing a SOAP API.

1. **Create a SOAP API**: On the **SOAP API** page, select **➕** or **Create**, then choose a creation method — provide a **WSDL URL**, import a WSDL file, or import a ZIP file containing WSDL and related schema files.
1. **Review the structure**: Review the generated service definitions, schemas, and elements in the **XML Structure** panel, and review the bindings and operations in the **Bindings** panel.
1. **Validate the API**: Select an operation, enter input values as needed, select **Run**, and review the response output to verify the service behavior.
1. **Save the schema**: Select **Save** to store updates in the current revision, or **Save as New Revision** to create a new version and maintain revision history.
1. **Update the API status**: Select **Change Status**, choose a lifecycle stage \(**Draft**, **Review**, **Approved**, or **Publish**\), enter a reason for the change, and select **Save** to apply the update.
