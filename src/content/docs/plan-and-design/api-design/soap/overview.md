A Simple Object Access Protocol \(SOAP\) API is a standardized protocol for exchanging structured information between applications over a network. SOAP uses XML-based messaging and supports multiple transport protocols, such as HTTP, HTTPS, SMTP, and TCP.

In APIwiz, you design and manage SOAP APIs in **Design Studio**. The platform enables you to:

- Import WSDL definitions and generate the service structure.
- Review bindings and operations.
- Test requests and responses.
- Manage the API lifecycle within a unified workflow.

SOAP is common in enterprise environments where reliability, security, and strict contract-based message validation are essential.

### Why use SOAP APIs in APIwiz

APIwiz supports SOAP APIs to help organizations design, govern, and manage enterprise-grade services within a unified API lifecycle platform. Many enterprises rely on SOAP-based services for mission-critical operations. APIwiz provides centralized visibility and governance for these services alongside REST and other API types.

#### Strong security support

SOAP supports enterprise security standards through WS-Security, including message encryption, digital signatures, authentication, and data integrity validation. APIwiz enables organizations to manage secure services within the same governance framework used for all other API types. This applies to financial services, healthcare systems, and other domains that handle sensitive data.

#### Reliable message delivery

SOAP supports reliable messaging and transactional standards that ensure message delivery, error handling, and consistency. APIwiz allows teams to govern business-critical services, such as payment processing and order management, where delivery guarantees and transaction reliability are essential.

#### Contract-based communication using WSDL

SOAP APIs use WSDL as a formal service contract, which ensures consistent request and response structures and clearly defined service operations. APIwiz uses this contract-based approach to automatically generate and manage SOAP API structures, supporting documentation, version control, and lifecycle management.

#### Enterprise and legacy system integration

Many enterprises continue to operate legacy systems built on SOAP. By supporting SOAP APIs in **Design Studio**, APIwiz enables organizations to:

- Integrate legacy systems with modern applications.
- Maintain backward compatibility.
- Govern older services using the same lifecycle controls applied to new APIs.

This reduces operational silos and centralizes API management across the organization.

#### Protocol and platform flexibility

SOAP APIs operate over multiple transport protocols, such as HTTP, HTTPS, SMTP, and TCP. APIwiz ensures these services can be designed, reviewed, versioned, and governed regardless of the underlying transport mechanism, supporting cross-platform interoperability.

#### Standardization and compliance

SOAP adheres to strict industry standards, making it suitable for regulated industries. APIwiz enables organizations to apply governance policies, approval workflows, and version control consistently across modern and legacy API types.

### SOAP APIs in APIwiz Design Studio

Supporting SOAP APIs in **Design Studio** enables organizations to manage enterprise and legacy services within a unified API lifecycle workflow. By incorporating SOAP into APIwiz, teams can:

- Apply centralized governance to SOAP services alongside REST and other API types.
- Maintain version control and revision history for WSDL-based APIs.
- Enforce lifecycle management through structured status transitions, such as **Draft**, **Review**, **Approved**, and **Published**.
- Validate service behavior using built-in request and response testing.
- Ensure compliance and security standards through consistent API management practices.

This enables organizations to govern legacy SOAP services with the same visibility, control, and compliance framework applied to modern APIs, eliminating silos between legacy and modern architectures.
