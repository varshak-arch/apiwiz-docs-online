Apigee is Google Cloud's API management platform. It acts as an intermediary, an API proxy; between backend services and client applications, letting organizations securely create, deploy, secure, and monitor their APIs.

It handles centralized traffic management, authentication, policy enforcement, caching, and analytics, so backend services don't need to implement these individually.

## How Apigee fits into APIwiz

Managing gateways like Apigee, Kong, or Axway individually through their own separate interfaces is inefficient. APIwiz acts as a unified platform where you can design proxies, configure policies, and deploy to Apigee, all from one place without logging into the native Apigee console.

The overall flow looks like this:

**Design → Build → Configure → Deploy → Publish as Products**
