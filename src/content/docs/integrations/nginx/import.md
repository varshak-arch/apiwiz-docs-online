---
title: "Import"
---

The Import tab lets you bring an existing Nginx configuration into APIwiz. This is a **3-step process**.

**Step 1: Select Connector**

1. Select a connector from the **Select Connector** dropdown.
1. Optionally, upload a ZIP file by selecting **Browse**, or drag and drop it into the upload area. Some connectors come preloaded, so you may not need to upload any files.
1. Select **Upload** to proceed to the next step.
