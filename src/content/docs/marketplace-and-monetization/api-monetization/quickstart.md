This quickstart walks you through configuring monetization dependencies, building and publishing an API package, and subscribing to it as a consumer.

1. [Configure monetization entities](/marketplace-and-monetization/api-monetization/configure-monetization-entities/manage-tab-overview/): Define core dependencies, including rate cards, currency sets, and metering rules.
1. [Create a monetization package](/marketplace-and-monetization/api-monetization/monetization-package/): Specify package metadata, such as name, category, valid-till date, fallback rate card, and visibility.
1. [Publish the monetization package](/marketplace-and-monetization/api-monetization/publishing-a-package/): Update the package status to make it available in the Developer Portal marketplace.
1. [Associate with a gateway product](/marketplace-and-monetization/api-monetization/associating-with-a-gateway-product/): Bind the monetization package to a gateway product and configure quota and resource access.
1. [Register and subscribe as a consumer](/marketplace-and-monetization/api-monetization/subscription-and-access-flow/): Subscribe to the package as a consumer and register a developer app to generate access credentials.
