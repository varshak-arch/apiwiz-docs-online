---
title: "Publish packages"
---

After you create a draft monetization package, publish it to make it active for API consumers. For more information, see [Changing the package status](/marketplace-and-monetization/api-monetization/manage-packages/).

Consumers can now view the package details under its designated category and review its attached rate cards.

### Viewing a published package in the Developer Portal

To view a published package as a consumer:

1. Log in to the Developer Portal.
1. Go to **API Packages** in the marketplace.
1. Locate the package's category.
1. Open the package to view its details and attached rate card.

For more information, see [Viewing packages](/marketplace-and-monetization/api-marketplace/core-usage/package/).
