Use the **Workspace Configuration** menu to manage workspace-level settings and access key actions related to your APIwiz environment.

### Access the configuration menu

To open the configuration menu, select your user avatar in the top-right corner of the UI.

The menu provides the following options:

### Update settings

To access user profile and application configuration options, do the following:

1. Select your user avatar in the top-right corner of the UI.
1. Select **Settings**.

The **Settings** screen opens, allowing you to update account information, manage user roles and permissions, and configure security preferences.

### Log out

To end your current session, do the following:

1. Select your user avatar in the top-right corner of the UI.
1. Select **Logout**.

The system logs you out of the application and redirects you to the login screen.

### Switch between dark and light mode

Use the **Dark/Light Mode** toggle, represented by a moon-and-stars icon, to switch between interface themes.

To switch themes, do the following:

1. Locate the **Dark/Light Mode** toggle at the bottom-left corner of the UI.
1. Select the toggle to switch between dark and light mode.

## Settings

Use the **Settings** page to manage your workspace configuration, including user profile, access control, team management, activity tracking, and billing information.

### Access the Settings page

To access the **Settings** page, do the following:

1. Select your user avatar in the top-right corner of the UI.
1. Select **Settings**.

The system redirects you to the **Settings** page.
